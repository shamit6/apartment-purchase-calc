# מחשבון רכישת דירה

מחשבון מתקדם לחישוב הון עצמי, משכנתא והוצאות רכישת דירה בישראל.

## תכונות

- **חישוב הון עצמי**: שווי דירה נוכחית + קרן השתלמות (עם אפשרות הלוואה) + חסכונות - משכנתא קיימת
- **חישוב הוצאות רכישה**: מס רכישה פרוגרסיבי, דמי תיווך עם מע"ם, והוצאות נוספות
- **חישוב דו-כיווני**:
  - מחיר דירה → סכום משכנתא
  - סכום משכנתא → מחיר דירה (עם חישוב מחדש של מיסים ועמלות)
- **ממשק בעברית** עם פורמט RTL
- **חישוב בזמן אמת** עם עדכון אוטומטי

## התקנה ופיתוח מקומי

### דרישות מקדימות
- [Bun](https://bun.sh/) (גרסה 1.0 ומעלה)

### התקנה

```bash
# התקנת תלויות
bun install
```

### הרצה מקומית

```bash
# הפעלת שרת פיתוח
bun run dev
```

הפתח דפדפן וגש ל-http://localhost:4321

### בנייה לפרודקשן

```bash
# בניית הפרויקט
bun run build

# תצוגה מקדימה של גרסת פרודקשן
bun run preview
```

## בדיקות

```bash
# הרצת בדיקות החישובים
bun run test-calculator.ts
```

## פרטי חישוב

### מס רכישה (מדרגות פרוגרסיביות)
- 0% עד ₪1,978,745
- 3.5% מ-₪1,978,745 עד ₪2,347,040
- 5% מ-₪2,347,040 עד ₪6,055,070
- 8% מ-₪6,055,070 עד ₪20,183,565
- 10% מעל ₪20,183,565

### דמי תיווך
- ברירת מחדל: 2% ממחיר הדירה
- כולל מע"ם 18%
- ניתן לשינוי בממשק

### קרן השתלמות
- אפשרות לקיחת הלוואה: 60% מהסכום נלקח כהלוואה
- ללא הלוואה: כל הסכום משמש כהון עצמי

### חישוב דו-כיווני
המחשבון תומך בשני כיווני חישוב:

1. **ממחיר דירה**: משתמש מזין מחיר דירה → המערכת מחשבת משכנתא נדרשת
2. **מסכום משכנתא**: משתמש מזין סכום משכנתא → המערכת מחשבת מחיר דירה מתאים (כולל חישוב מחדש של מיסים ועמלות)

השיטה השנייה משתמשת באלגוריתם איטרטיבי (Newton-Raphson) למציאת מחיר הדירה המדויק.

## פריסה ל-GitHub Pages (אופציונלי)

לפריסה ל-GitHub Pages:

1. צור repository ב-GitHub
2. עדכן את `astro.config.mjs`:
   ```javascript
   export default defineConfig({
     site: 'https://your-username.github.io',
     base: '/apartment-purchase-calc',
   });
   ```
3. צור `.github/workflows/deploy.yml` (ראה תיעוד Astro)
4. אפשר GitHub Pages בהגדרות ה-repository
